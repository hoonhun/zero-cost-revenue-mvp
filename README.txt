# 0원 수익 시스템 MVP — 제작·판매 손익 계산기

## 포함 파일
- `index.html`: 별도 설치나 서버 없이 브라우저에서 실행되는 손익 계산기
- `사업화_실행계획.md`: 무료 배포, 시장 검증, 수익화 단계
- `시장검증_1일차.md`: 기존 경쟁 도구 검토와 초기 판단
- `시장검증_2일차.md`: 미판매 재고 기능 개선, 계산 테스트 및 다음 검증 과제
- `무료배포_체크리스트.md`: GitHub Pages 공개 배포를 위한 사용자 단계별 안내

## 로컬 실행
`index.html` 파일을 Chrome/Edge에서 열면 됩니다. 계산은 브라우저에서 수행되며 입력값을 별도 서버로 보내지 않습니다.

## 중요
파일을 만든 것만으로 수익이 발생하지 않습니다. 공개 배포를 위해서는 운영자 본인의 계정 생성, 저장소 생성, 게시 설정 등 사용자 조치가 필요합니다. 광고 수익은 방문자 수, 광고 정책 승인, 국가·기기별 광고 단가 등에 좌우됩니다. 현재 수익은 0원이며, 방문자 데이터도 없습니다.
